# Dependency Visualizer

CLI-приложение для анализа и визуализации графа
зависимостей Python-пакетов.

## Требования

- Python 3.11 или новее.
- Git для сохранения истории изменений.

Используются только стандартные модули 
Python. Сторонние библиотеки для получения 
зависимостей пакетов не используются.

## Структура проекта

```text
dependency-visualizer/
├── main.py
├── config.py
├── config.toml
├── test-repository.txt
├── .gitignore
└── README.md
```

## Запуск

Запуск приложения с конфигурацией по умолчанию:

```bash
python main.py
```

Чтобы указать другой файл конфигурации:

```bash
python main.py another-config.toml
```

Если имя файла не указано, используется `config.toml`.

## Конфигурация

Параметры приложения задаются в файле `config.toml`.

Пример конфигурации:

```toml
package_name = "requests"
repository = "./test-repository.txt"
test_repository_mode = true
version = "2.32.0"
ascii_tree = true
filter_substring = "test"
```

### Описание параметров

| Параметр | Тип | Описание |
|---|---|---|
| `package_name` | Строка | Имя анализируемого пакета |
| `repository` | Строка | Путь к тестовому файлу или URL репозитория |
| `test_repository_mode` | Логический | Включает тестовый режим при значении `true` |
| `version` | Строка | Версия анализируемого пакета |
| `ascii_tree` | Логический | Включает вывод графа в виде ASCII-дерева на последующих этапах |
| `filter_substring` | Строка | Подстрока для исключения пакетов из графа на последующих этапах |

## Реализованные возможности

- Чтение конфигурации в формате TOML.
- Проверка наличия обязательных параметров.
- Проверка типов и форматов значений.
- Проверка пути к тестовому файлу или структуры URL.
- Обработка ошибок чтения файла и синтаксиса TOML.
- Вывод параметров конфигурации в формате «ключ — значение».
- Обработка ошибок аргументов командной строки.

## Обработка ошибок

Приложение проверяет корректность конфигурации и выводит сообщения об ошибках, если:

- конфигурационный файл отсутствует;
- TOML-файл содержит синтаксическую ошибку;
- обязательные параметры не указаны;
- значения имеют неправильный тип или формат;
- тестовый файл не найден;
- URL не соответствует поддерживаемому формату;
- передано слишком много аргументов командной строки.
