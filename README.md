# Граф зависимостей пакетов

## Описание

Консольное приложение на Python для построения графа зависимостей пакетов.

## Реализованные возможности

- Чтение и проверка конфигурации TOML.
- Получение прямых зависимостей из PyPI.
- Работа с тестовым репозиторием JSON.
- Построение транзитивного графа алгоритмом BFS с рекурсивной обработкой очереди.
- Исключение пакетов, содержащих заданную подстроку в имени.
- Обработка циклических зависимостей.
- Вывод графа в консоль.


## Для указания конфигурационного файла:

```bash
python main.py path/to/config.toml
```

## Тестовый режим

В тестовом режиме `test_repository_mode = true` приложение использует JSON-файл вместо URL репозитория.

Пример конфигурации:

```toml
package_name = "A"
repository = "tests/stage3/repository.json"
test_repository_mode = true
version = "1.0.0"
ascii_tree = true
filter_substring = ""
```

Пример тестового репозитория:

```json
{
  "A": ["B", "C"],
  "B": ["D"],
  "C": ["D", "E"],
  "D": ["F"],
  "E": [],
  "F": [],
  "G": ["H"],
  "H": ["G"],
  "I": []
}
```

## Демонстрация этапа 3

В директории `tests/stage3/` подготовлены конфигурации для пяти сценариев:

| Конфигурация | Проверяемый случай |
|---|---|
| `config_basic.toml` | Транзитивные и общие зависимости |
| `config_cycle.toml` | Циклические зависимости |
| `config_filter.toml` | Фильтрация по подстроке |
| `config_empty.toml` | Пакет без зависимостей |
| `config_missing.toml` | Отсутствующий пакет |

Для запуска всех сценариев:

```bash
python tests/stage3/run_demos.py
```

Скрипт последовательно запускает приложение для каждого конфига и выводит параметры конфигурации и результат работы.

### Пример результата

Для `config_basic.toml` приложение выводит параметры:

```text
Параметры конфигурации:
package_name = A
repository = tests/stage3/repository.json
test_repository_mode = True
version = 1.0.0
ascii_tree = True
filter_substring =
```

Затем выводит граф:

```text
Граф зависимостей:
A:
  -> B
  -> C
B:
  -> D
C:
  -> D
  -> E
D:
  -> F
E:
  (нет зависимостей)
F:
  (нет зависимостей)
```
